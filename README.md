# Sensory SafeScape

A calm, predictable Android app for autistic and sensory-sensitive children (ages 2–10):

- **Calming Canvas**: touch and drag to stir soft glowing waves (multi-touch), with a 4-in / 6-out breathing ring and Sammy the Turtle breathing along.
- **My Visual Routines**: step-by-step picture cards with a First/Then strip, spoken micro-stories, a gentle chime and a small star burst. Eight ready-made routines; parents can build their own with photos.
- **Soothing Sounds**: warm hum, soft rain, ocean waves and a marimba lullaby, all filtered to remove high pitches, with a slow bedtime fade.
- **Wait Timer**: a shrinking disc (no numbers, no alarm) showing what comes next.
- **Grown-ups area** (behind a multiplication gate): sensory sliders, routine builder, several children, the "Calm & Focus Horizon" progress view and a one-tap PDF summary for therapists.

No sign-up is needed. Data lives on the device; an optional private cloud backup (Firebase) keeps it safe across devices. No ads, analytics or tracking.

See `docs/design-review-v1.md` for the locked design decisions and `docs/testing.md` for how it is tested.

Pictograms: [Noto Emoji](https://github.com/googlefonts/noto-emoji) (Apache 2.0). Font: [Andika](https://software.sil.org/andika/) (SIL OFL 1.1). All sounds and artwork are generated in code (`scripts/`).
